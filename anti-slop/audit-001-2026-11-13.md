## Root Cause Analysis (Diagnosing-Bugs Phase 1-3)

**Feedback loop for sync issue:**
```powershell
& 'C:\flutter\bin\flutter.bat' run
# 1. Pull to refresh → providers reload → UI updates
# 2. Observe: network.lastSyncTime unchanged → timestamp still old
# 3. Cause: HomeScreen._syncData() bypasses NetworkService._syncBukuData()
```

**Hypotheses (ranked):**
1. **H1 (Confirmed):** `HomeScreen._syncData()` calls providers directly but doesn't call `NetworkService.checkConnection()` or `_syncBukuData()`, so `lastSyncTime` never updates.
2. **H2:** `NetworkService._syncBukuData()` only fetches 1 book (`per_page=1`) — may not represent full data freshness.
3. **H3:** Periodic timer in `NetworkService` (15s) and `HomeScreen` (30s) run independently; race conditions possible.
